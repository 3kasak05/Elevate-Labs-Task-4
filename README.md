# Elevate-Labs-Task-4
Google colab Classification with Logistic Regression
 Logistic Regression Binary Classifier
This repository contains a complete solution for building a binary classification model using Logistic Regression with Python's scikit-learn library. The project uses the Breast Cancer Wisconsin (Diagnostic) Dataset to predict whether a tumor is malignant (0) or benign (1).

## Objective
To demonstrate a robust machine learning workflow for binary classification, covering data preparation, model training, evaluation, and hyperparameter tuning (threshold adjustment).

## Tools & Technologies
Python

scikit-learn: For model building and evaluation.

Pandas: For data handling and manipulation.

Matplotlib/Seaborn: For data visualization (e.g., Confusion Matrix, ROC Curve).

Jupyter/Colab Notebook: For step-by-step execution and documentation.

##Project Steps
The notebook follows a standard machine learning pipeline:

Data Loading: Load the Breast Cancer Wisconsin dataset.

Preprocessing: Perform a Train/Test Split and use StandardScaler to standardize features.

Model Training: Fit the Logistic Regression model on the training data.

Prediction: Generate class predictions and prediction probabilities on the test set.

Evaluation: Assess model performance using key classification metrics.
